Turbo Budżet — pakiet do GitHub Pages
1. Rozpakuj ZIP.
2. Wgraj CAŁĄ zawartość bezpośrednio do głównego katalogu repozytorium publikowanego przez GitHub Pages.
3. Podmień index.html, manifest.json, sw.js i folder icons.
4. Otwórz stronę w Safari. Na ekranie PIN dostępny jest przycisk resetu.
UWAGA: reset usuwa lokalny zaszyfrowany sejf (miesiące, wydatki i oszczędności), po czym można ustawić nowy PIN. Nie odzyskuje starego PIN-u ani danych.
Kategorie broni i amunicji zostały usunięte z wyboru wydatków; dodano Mieszkanie i Remonty oraz nowe kategorie z ikonami w stylu z przesłanego zrzutu.

Dodano stronę manual.html z instrukcją obsługi w stylu synthwave; otworzysz ją linkiem „Instrukcja obsługi” w stopce aplikacji.
Nazwa aplikacji została ujednolicona do „Turbo Budżet”.


NOWA WERSJA — WYBÓR JĘZYKA
Na ekranie startowym, jeszcze przed wpisaniem PIN-u, znajduje się lista rozwijana z flagami. Ustawienie języka zapisuje się na tym urządzeniu i jest również dostępne w Ustawieniach. Lista zawiera 20 języków: polski, angielski, czeski, niemiecki, włoski, francuski, hiszpański, portugalski, szwedzki, norweski, duński, niderlandzki, kaszubski, ukraiński, rosyjski, rumuński, węgierski, słowacki, fiński i grecki.
